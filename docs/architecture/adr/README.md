# Architecture Decision Records

This folder stores active ADRs for architectural and structural decisions.

## Rules

- Use incremental IDs: `0001-...`, `0002-...`
- One decision per file.
- Include context, decision, consequences.
- Do not rewrite historical ADRs; add a new ADR to supersede older decisions.
