Legacy schema script notes
==========================

This file used to contain an early prototype schema for the old `Tb*` table
model. That model is obsolete. The current application schema uses the
canonical tables in `apps/api/database/schema/BASE_SCHEMA.sql`, including
`dbo.Users`, `dbo.Posts`, `dbo.Categories`, and `dbo.PostImages`.

Current database setup should use:

- `apps/api/database/schema/BASE_SCHEMA.sql`
- `apps/api/database/scripts/migrations/`
- `apps/api/database/scripts/seeds/baseline/`
- `apps/api/database/scripts/seeds/dev/`

For sample marketplace posts, use:

- `apps/api/database/scripts/seeds/dev/INSERT_SAMPLE_POSTS.sql`

Or run:

```bash
./scripts/bootstrap_db.sh --with-sample-posts
```
