Legacy stored procedure notes
=============================

This file used to contain early prototype stored procedures for the old
`Tb*` table model. Those examples are no longer runnable against the current
TijarahJo database schema and were removed to avoid confusion.

Current database objects live under:

- `apps/api/database/schema/BASE_SCHEMA.sql`
- `apps/api/database/scripts/migrations/`
- `apps/api/database/scripts/seeds/baseline/`
- `apps/api/database/scripts/seeds/dev/`

For sample marketplace posts, use the current seed script:

- `apps/api/database/scripts/seeds/dev/INSERT_SAMPLE_POSTS.sql`

Or apply the generated bundle through the bootstrap script:

```bash
./scripts/bootstrap_db.sh --with-sample-posts
```
